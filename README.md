## 🚀 Getting Started

Clone the repository:
```bash
git clone https://github.com/allproject121/OSINT-Tool.git
cd OSINT-Tool
```

Navigate to any individual tool directory and review its specific requirements (Python `requirements.txt`, Node `package.json`, or Go binaries) to run.
